# The school spelling lists, for the Spelling Bee game.
# Each week starts with its test date:  [Week 5: 14.10.26]
# then one word per line:  word | a short sentence that uses it (the sentence is optional)
# The game plays the next test's words, and moves on to the next week at 3pm on test day.
# Then run:  npm run spelling   (needs Python with edge-tts: pip install edge-tts)
# Full steps: README.md, "A new spelling list each week".
